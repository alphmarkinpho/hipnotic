⚙️ Configurar sincronização

Siga os passos abaixo — leva cerca de 5 minutos

📝 Como configurar este arquivo:

Clique com o botão direito no arquivo todo.html → "Abrir com" → Bloco de Notas (ou Notepad++, VS Code).
Procure o trecho FIREBASE_CONFIG no início do script e preencha os campos com os valores do Firebase.
Salve com Ctrl+S e reabra no navegador.

1
Acesse console.firebase.google.com com sua conta Google e clique em Criar projeto
2
Dê um nome (ex: meu-todo), desative Google Analytics e finalize
3
No painel do projeto, clique no ícone </> Web, dê um nome e clique em Registrar app
4
O Firebase vai mostrar um bloco com apiKey, authDomain, databaseURL etc. Copie cada valor e coloque no FIREBASE_CONFIG do arquivo
5
No menu esquerdo: Authentication → Sign-in method → Google → Ativar
6
No menu esquerdo: Realtime Database → Criar banco de dados → Modo de teste → Próximo
⚠️ O databaseURL só aparece depois de criar o Realtime Database
7
No Realtime Database → aba Regras → substitua o conteúdo por:
{ "rules": { "todos": { "$uid": { ".read": "auth != null && auth.uid === $uid", ".write": "auth != null && auth.uid === $uid" } } } }
Clique em Publicar
8
Salve o arquivo todo.html e reabra no navegador — esta tela não vai mais aparecer!
